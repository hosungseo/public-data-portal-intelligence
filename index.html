어느 시점의 데이터인가

목록·메타는 2026년 현행본, 이용이력은 공식 최신 연간본인 2024년 말 기준입니다. 서로 다른 기준시점을 숨기지 않고 같이 표시합니다.

읽는 법: U·M은 현재 카탈로그 구조와 카운터를, Y는 2024년까지의 연간 이용 흐름을 보강합니다. ‘누적 신호’는 채널별로 연간 이력이 있으면 이를 우선하고, 없으면 현재 카운터를 사용합니다.

  • 지원센터목록·메타·이용이력 3종 결합
  • 같은 기관이 두 자리 이상 차지하지 않도록 배분

전환은 무엇을 줄이나

파일은 내려받고 구조를 해석하는 절차가 반복됩니다. API는 반복 조회·갱신·자동화가 필요한 경우 그 마찰을 크게 줄입니다. 아래 수치는 절감량의 확정치가 아니라, 어디서 그 효과를 먼저 검토할지 보여주는 이용 신호입니다.

—

  2. ②데이터셋 페이지 열기
  3. ③CSV·HWP·XLSX 다운로드
  4. ④인코딩·파싱·정리

방법론과 공개 범위

이 페이지는 자동 판정기가 아니라, 사람이 API 전환 검토 우선순위를 빠르게 읽기 위한 경량 리뷰 화면입니다.

파일과 API
파일은 원본·대용량 배포에, API는 반복 조회·부분 조회·자동화에 강합니다. 이 페이지는 둘 중 무엇이 더 맞는지 검토할 후보를 수요·메타·정책 신호로 정렬합니다.
공개 요약 자산
이 페이지가 하는 일·하지 않는 일
이 페이지는 전환 우선순위를 제안하지만 자동 승인하거나 API 적합성을 확정하지 않습니다. 파일 유지·API 병행·API 전환 중 어떤 방식이 맞는지는 사람의 판단이 필요합니다.
추가 검토 필요
실제 API 전환 여부는 스키마, 최신성, 권리, 호출량·버전·장애 대응을 포함한 운영 가능성 검토가 추가로 필요합니다.
공개 범위
전체 원천데이터와 내부 중간분석 파일은 포함하지 않고, 공개 가능한 경량 요약 자산만 사용합니다.
